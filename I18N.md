# GachaHub Internationalization (v0.12)

GachaHub contains a lightweight built-in i18n layer with no external translation runtime dependency.

## Languages

- German (`de`) – Deutsch
- English (`en`) – English
- French (`fr`) – Français
- Spanish (`es`) – Español

The selected language is stored in the existing persistent settings store and updates the React UI immediately.

## Files

- `src/i18n/index.ts` – dictionaries, interpolation and `useI18n()` hook
- `src/components/LanguageSwitcher.tsx` – quick DE/EN/FR/ES selector in the game top bar
- `src/lib/settings.ts` – `LanguageKind`

## Adding a translation

Use a semantic key:

```tsx
const { t } = useI18n();
return <button>{t('common.install')}</button>;
```

Variables use `{{name}}`:

```tsx
t('global.dim', { value: 58 })
```

## Adding another language later

1. Extend `LanguageKind` in `src/lib/settings.ts`.
2. Add a dictionary in `src/i18n/index.ts`.
3. Add the language to `dictionaries`.
4. Add it to the language selectors.

Technical provider messages and third-party text can intentionally remain untranslated when they come directly from a backend/provider. Launcher-owned UI should use `t(...)`.

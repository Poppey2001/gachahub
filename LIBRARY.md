# GachaHub v0.11 – Flexible Game Library

Die linke Game Rail ist jetzt eine persönliche Bibliothek.

- `+` öffnet den Katalog aller von GachaHub unterstützten Spiele.
- Spiele können hinzugefügt oder wieder ausgeblendet werden.
- Die Reihenfolge kann im Katalog mit Hoch/Runter geändert werden.
- Die Auswahl wird in `localStorage` unter `gachahub-library-v1` gespeichert.
- Es können nur Spiele hinzugefügt werden, die vom Backend/Game-Manifest geliefert werden.
- Mindestens ein Spiel bleibt in der Rail, damit die Hauptansicht nie ohne Zielspiel ist.

Aktuell im eingebauten Katalog: Arknights, Arknights: Endfield, Genshin Impact,
Honkai: Star Rail, Zenless Zone Zero, Wuthering Waves und GIRLS' FRONTLINE 2: EXILIUM.
